Εκκίνηση του chatbot:
cd D:\museum_bot
.\rasa\Scripts\Activate
cd D:\museum_bot\chatbot
rasa shell

Επανεκπαίδευση:
cd D:\museum_bot\chatbot
rasa train

Δοκιμή και χρήση του chatbot
cd D:\museum_bot
.\rasa\Scripts\Activate
cd D:\museum_bot\chatbot
rasa shell

Για να δουλεψει σωστα με actions θελει δευτερο τερμαντικο:
cd D:\museum_bot
rasa\Scripts\activate.bat
cd chatbot
rasa run actions

Για να δουλεψει με μηνυματα από html θελουμε:
2 cmd
το 1 είναι με το rasa run actions
το 2 είναι με το rasa run --enable-api --cors "*"
